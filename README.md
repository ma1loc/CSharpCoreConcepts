## 🗺️ Learning Roadmap

### ✅ Phase 1 — C# Core Language
- OOP: class, record, struct, interface
- Properties: get, set, init, required
- Collections: List, Dictionary, Stack, Queue
- Generics and IEnumerable
- async / await / Task
- Dependency Injection (manual)
- MVC Architecture
- JSON Serialization / Deserialization
- Custom Attributes

### 🔜 Phase 2 — ASP.NET Core Web API
- Controllers and routing
- HTTP methods: GET, POST, PUT, DELETE
- Middleware pipeline
- Dependency Injection container
- Request/Response lifecycle
- Swagger / OpenAPI

### 🔜 Phase 3 — Authentication & Authorization
- JWT (JSON Web Tokens)
- Cookie-based auth
- Role-based authorization
- ASP.NET Core Identity

### 🔜 Phase 4 — Database Integration
- Entity Framework Core
- Code-first migrations
- Repository pattern
- LINQ queries

### 🔜 Phase 5 — Real-Time Communication
- SignalR fundamentals
- Hubs and connections
- Real-time events
